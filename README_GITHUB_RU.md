# Загрузка Playerok Universal на GitHub одним действием

**Для репозитория:** https://github.com/gkhkfmkh/playerok_universal_fixed

В этом архиве `server.py`, `bot.py`, `requirements.txt`, `tgbot/`, `core/`, `playerokapi/` находятся **сразу в корне**. Вложенной папки `playerok-universal-main` нет.

## Windows — самый простой способ

1. Установи **Git for Windows**: https://git-scm.com/download/win (если уже установлен — пропусти).
2. Распакуй **весь ZIP** на компьютер.
3. Открой распакованную папку и запусти двойным щелчком **`UPLOAD_GITHUB.bat`**.
4. Если GitHub попросит войти в аккаунт — авторизуйся. Если Git запросит имя/почту для коммита — укажи свои данные.
5. После сообщения `SUCCESS` открой репозиторий и проверь, что **`server.py` виден сразу на главной странице**.

Скрипт сам клонирует существующий репозиторий, **заменит его файлы** на актуальную сборку, удалит прежнюю вложенную папку `playerok-universal-main` и отправит **один коммит**. История репозитория остаётся; **force-push не используется**. Если в репозитории есть важные файлы, предварительно сохрани их.

Скрипт **не сможет отправить файлы**, если у компьютера нет Git или если нет доступа к репозиторию. Тогда он выведет ошибку; до успешного `push` содержимое GitHub не изменится.

## Linux и macOS

В папке с распакованным проектом:

```bash
bash UPLOAD_GITHUB.sh
```

## Хостинг

После успешной отправки настрой:

- **Файл запуска:** `server.py` (без слешей).
- **Python:** `3.12`.
- **Установка зависимостей:** `python -m pip install -r requirements.txt`.
- **Тип процесса:** worker/background; бот использует Telegram polling, а не веб-сервер.
- **Токен:** переменная окружения `TELEGRAM_BOT_TOKEN` (для хостинга без интерактивной консоли).

Если хостинг уже привязан к репозиторию, **запусти повторный деплой** последнего коммита: одного `git push` не всегда достаточно, чтобы обновились файлы `/app`.

**Не публикуй токены, cookies, персональные настройки и файлы склада.** Папки `bot_settings/`, `bot_data/`, `modules/` и `.env` исключены из Git и должны храниться отдельно на постоянном диске хостинга.

## Важно

GitHub через веб-интерфейс ограничивает количество файлов, загружаемых за одно действие. Архив содержит больше 100 файлов, поэтому **не загружай их по одному через браузер**: используй скрипт/GitHub Desktop. Git позволяет отправлять больше 100 файлов одним коммитом.

Проверки синтаксиса и стартовой диагностики не заменяют реальный тест с Telegram и Playerok. Не включай автоматическую выдачу ценных товаров до тестовой сделки.
